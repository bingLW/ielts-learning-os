# v2.5 Listening & Speaking Lab — 用户手册

## 1. 定位

v2.5 建立**可持续使用的听力与口语训练、诊断、证据采集和复测工作台**：把音频、转写、任务、作答与学习证据整合为一个闭环，并增强 v2.4.1 的听说基线与复测能力。

## 2. 两个新入口

侧栏「诊断」分组新增两项：

| 入口 | 路径 | 能力 |
| --- | --- | --- |
| 听力实验室 | `/listening` | 上传音频 → 播放 → 盲听/听写/复述 → 转写对照 → 错误标记 |
| 口语实验室 | `/speaking` | 选题目 → 麦克风录音 → 回放 → 重录 → 保存历史 take |

## 3. 听力实验室用法

1. **上传音频**：右上角「上传音频」，支持 mp3 / m4a / wav / webm / ogg / aac，单文件 ≤ 50MB。
2. **播放器**：播放/暂停、0.75x / 1x / 1.25x 变速、A-B 循环（先点一次设起点，再点一次设终点）。
3. **转写对照**：机器转写（如已接入 ASR）与手动转写分版本展示，附时间戳与置信度。
4. **练习与作答**：首听结果与辅助后结果**分开保存**，绝不覆盖；错误标记中「音频质量」不计为英语能力问题。

> 提示：首次打开是空态，因为音频与练习只反映你真实上传与作答的数据。

## 4. 口语实验室用法

1. **选题目**：右侧题目列表，覆盖朗读 / 简短问答 / 话题独白 / 复述 / 角色扮演等九类。
2. **录音**：点「开始录音」→ 浏览器请求麦克风权限 → 允许后录音 → 点「停止」。
3. **回放与重录**：停止后本地回放；可多次重录，**历史 take 都保留**（不会覆盖）。
4. **保存**：点「保存录音」落盘本机，数据库只存相对路径 + 哈希。
5. **数据说明**：录音仅存本机；若调用外部 AI 会先征求你的同意。

## 5. ASR 与转写

- 当前**未接入外部 ASR 服务**，转写需手动提交（这是有意的安全默认，不是缺陷）。
- 机器转写（接入后）与你的修订版**分版本保存**，低置信度会提示核验，绝不当作标准答案。
- 绝不把 ASR 转写准确率当作发音分数。

## 6. 退出系统

`/settings` 底部新增「退出系统」卡片：点击 → 二次确认 → 优雅关闭本机应用进程（`npm run dev` / `next start`）。

## 7. 已知限制

- 未接入真实 ASR / TTS / 发音分析 Provider，语音转写当前走手动降级。
- 录音上限约 1.6MB / 90 秒（沿用 v2.4.1 约定）。
- 口语 AI 反馈依赖 v2.4 外部 AI 通道；未启用时仅保存录音与作答，不产出评分。
- 等级为 AI 辅助估计，非官方 CEFR 认证，不预测 IELTS 分数。

## 8. 隐私与删除

- 音频与录音只落本机 `storage/uploads`（gitignore，不提交）。
- 删除会话/录音时，派生转写、反馈与证据引用按删除策略处理。
- 外部 AI 调用前会明确告知用途并征求同意。
