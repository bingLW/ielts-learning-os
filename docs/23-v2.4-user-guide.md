# v2.4 使用手册：AI Learning Coach

本手册面向日常使用者，说明如何在 IELTS Learning OS v2.4 中完成一次完整的 AI 教学闭环，以及如何管理模型、预算、隐私与证据。

> 一句话：**先独立作答，再看 AI 诊断；提示逐级解锁，复测必须脱离提示；AI 的所有评估都只是练习反馈，不是官方分数。**

---

## 1. 入口与默认行为

| 项目 | 说明 |
| --- | --- |
| 一级入口 | 左侧导航「AI Learning Coach」→ `/ai-coach` |
| 会话详情 | `/ai-coach/[id]` |
| 复习视图 | `/ai-coach/review` |
| 用量与预算 | `/ai-coach/usage` |
| 模型与提示词管理 | `/ai-coach/admin` |

**开箱即用**：未配置任何模型密钥时，系统使用内置 Mock Provider。它输出确定性的示例内容，不联网、不产生费用，适合先把流程走通。页面顶部会显示当前 Provider。

---

## 2. 新建一次学习会话

在 `/ai-coach` 首页填写：

| 字段 | 说明 |
| --- | --- |
| 教学模式 | Tutor 讲解 / Socratic 苏格拉底 / Examiner 模拟考官 / Error Analyst 错误分析员 / Drill 练习生成 / Reviewer 复习教练 |
| 技能 | 听力 / 阅读 / 口语 / 写作 / 语法 / 词汇 |
| 目标等级（可选） | A0–C1；留空表示由 AI 自动判断 |
| 本次学习目标 | 用中文写清楚「这次要练什么、希望达到什么」，例如「用一般过去时描述上周末的两件事」 |

创建后进入会话详情页，状态从「已创建」开始推进。

---

## 3. 一次完整闭环（五步）

### 第 1 步：独立基线

- 先看「本次任务（TaskSpec）」的指令与预计时长；
- 在「第 1 步：独立基线」里**自己写**，不要查翻译；不确定的地方可以写「不确定」；
- 点「保存独立基线」。

保存后会发生三件事：

1. 你的原文作为 BASELINE 证据写入 Evidence Center（A0、自评）；
2. 生成后续复测阶梯；
3. 原文**从此不可被 AI 覆盖**——AI 的诊断、讲解、反馈都不会改写这段文本。

### 第 2 步：诊断

点「请求诊断」。诊断结果必须引用你的原句；如果证据不足，会明确写「证据不足」，而不是编造结论。

### 第 3 步：提示 / 讲解 / 练习

| 操作 | 规则 |
| --- | --- |
| 请求第 1 级提示 | 只给方向，不泄露答案 |
| 请求第 2 级提示 | 更具体，但仍不给完整答案 |
| 请求第 3 级提示 | 可以给出完整示范；之后必须做独立复测 |
| 请求讲解 | 属于 assisted，会产生辅助轮次 |
| 生成变式练习 | 生成同知识点的平行练习；会话未完成时答案不会出现在页面上 |

提示**不能跳级**，必须 1 → 2 → 3。页面会显示「已用最高提示级别：N / 3」。

### 第 4 步：独立即时复测

- 换新题 / 新句 / 新主题，**不看此前提示**；
- 选择本次使用的辅助（无辅助 / 词典 / 翻译 / 笔记 / AI 提示）；
- 点「提交复测并评估」。

结果会写成 IMMEDIATE_RETEST 证据，评估者类型固定为 AI，并附带统一免责声明：

> AI 辅助评估，仅供练习反馈，不是官方 IELTS 分数或 CEFR 认证。

同时，基线排期里那条「即时复测」待办会自动结清，不会在 `/retest` 重复出现。

### 第 5 步：延迟复测

点「确认延迟复测排期」，系统按 7 / 30 / 84 天阶梯排期；到期后到 `/retest` 页完成。此时会话状态变为「已排延迟复测」。

### 可选：把诊断转为错题

在「把诊断转为错题（需你确认）」卡片里填写知识点、原题、我的答案、参考答案、错误原因，点「确认写入错题本」。AI 只给候选，**必须你确认**才会进入统一复习调度。

## 4. 反馈、暂停、导出与删除

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 标记 AI 反馈 | 「会话轮次」每条 AI 轮次下方 | 有帮助 / 没帮助 / 不准确，用于后续评估提示词质量 |
| 暂停 / 继续 | 「会话操作」 | 暂停保留现场，可随时继续 |
| 导出会话 JSON | 「会话操作」 | 导出当前会话的结构化数据，便于备份或分析 |
| 取消会话 | 「会话操作」 | 会话终止，但已写入的证据保留 |
| 删除会话 | 「会话操作」 | 二次确认后删除会话、轮次与调用日志；**关联证据保留**，仅解除 `aiSessionId` 关联 |

## 5. 页面说明

### 5.1 `/ai-coach/review`

列出所有产生过证据的 AI 会话，按更新时间排序，显示每条证据的类型、分数、辅助级别与评估者类型。用于快速回看「基线 → 即时复测 → 延迟复测」的证据链。

### 5.2 `/ai-coach/usage`

- 调用次数、会话数、tokens、估算成本、平均延迟、错误率；
- 每日趋势、状态分布、最近调用明细；
- 日 / 月预算进度与 80% 预警。

状态含义：

| 状态 | 含义 |
| --- | --- |
| `OK` | 外部模型调用成功 |
| `MOCK` | 模拟调用，不产生真实费用 |
| `ERROR` / `TIMEOUT` / `INVALID_OUTPUT` / `BLOCKED` | 失败、超时、输出不合法、预算拦截 |

### 5.3 `/ai-coach/admin`

- **Provider 状态**：显示当前使用 Mock 还是外部模型、回退原因与凭据来源；
- **Provider 凭据**：API Key、Base URL、模型名（v2.4.2 起可在页面填写，加密入库，只回显末四位）；
- **引擎设置**：外部 AI 总开关、每日预算、每月预算、预警比例、解释语言；
- **模型配置**：显示名称、输入/输出价格（USD / 百万 token），价格只用于成本估算；
- **Prompt Registry**：提示词模板与版本；版本只增不改，带 sha256 校验和，历史会话始终引用当时的版本。

默认预算：每日 $1、每月 $20、80% 预警。预算超限后新调用会被拦截并记为 `BLOCKED`，已有调用不回滚。

## 6. 接入外部模型（可选）

### 6.1 页面配置（推荐，v2.4.2 起）

1. 打开 `/ai-coach/admin`；
2. 在 **Provider 凭据** 填入 API Key、Base URL（如 `https://api.openai.com/v1`）、模型名（如 `gpt-4o-mini`），点击保存；
3. 打开「允许外部 AI（需已保存凭据）」并保存。

保存后立即生效，无需重启。API Key 使用 AES-256-GCM 加密后存入本机 SQLite，页面与接口只回显末四位；「清除 API Key」会立即回落环境变量或 Mock。

加密密钥优先取环境变量 `AI_CREDENTIALS_SECRET`；未设置时自动生成 `.local/ai-credentials.key`（权限 0600，已加入 `.gitignore`）。更换加密密钥后，已入库的 Key 无法解密，需要在页面重新填写。

### 6.2 环境变量回退（可选）

已有 `.env` 配置可继续使用，作为页面配置缺失时的回退：

```bash
AI_PROVIDER_API_KEY=sk-...
AI_PROVIDER_BASE_URL=https://api.openai.com/v1   # 可选
AI_PROVIDER_MODEL=gpt-4o-mini                    # 可选
```

解析优先级：管理页配置 > 环境变量 > 未配置。以下任一情况会自动回退 Mock，并在管理员页显示原因：

- 外部 AI 未开启；
- 页面与环境变量都没有有效 API Key；
- Base URL 不合法。

**密钥安全**：明文不写入源码、前端 bundle 或日志；入库前加密，页面只回显末四位。不要把 `.env` 提交到 Git。

## 7. 隐私与数据边界

| 规则 | 行为 |
| --- | --- |
| 最小上下文 | 只发送最近 5 条错误与 3 条证据摘要，不发送全部个人历史 |
| 脱敏 | 邮箱、Bearer Token、API Key、长数字串、`file://` 路径在发送与写日志前统一打码 |
| 结构化与文本分离 | `structuredJson` 与聊天文本分开存储，便于校验与审计 |
| 可追溯 | 每次调用记录 provider、model、prompt version、tokens、延迟、成本、状态与时间 |
| 不覆盖原始产出 | AI 输出永远不能改写你的基线答案、作文、录音或证据 |
| 不自动改计划 | AI 不会自动修改正式计划、删除数据或升级阶段；所有动作需你点击确认 |
| 删除语义 | 删除会话只删会话与日志，独立证据保留 |

## 8. 常见问题

**Q：为什么练习页看不到答案？**
会话未完成（未提交即时复测）时，练习答案被隐藏，避免提前看答案破坏独立复测。完成复测后即可查看。

**Q：为什么提示只有方向，没有答案？**
第 1–2 级提示被硬性限制为不泄露答案；需要完整示范时请解锁第 3 级，之后必须做不看提示的复测。

**Q：为什么调用被拦截？**
当日或当月估算成本超过了预算。到 `/ai-coach/admin` 调整预算，或等待下一个预算窗口。

**Q：为什么页面显示 Mock？**
没有配置密钥、没有打开外部 AI，或 Base URL 不合法。按第 6 节配置后重启并打开开关。

**Q：AI 分数能当雅思分数吗？**
不能。所有 AI 评估都标注「辅助评估」，`is_official_score` 恒为 `false`；正式成绩只来自你的真实考试或模考记录。

**Q：删除会话会丢证据吗？**
不会。基线、即时复测等独立证据会保留在 Evidence Center，只是不再关联该会话。

**Q：如何回退整个 v2.4？**
先停应用，再执行 `bash scripts/restore.sh backups/<迁移前备份>`，随后 `npm run db:generate`。详细步骤见 `README.md` §15.3。
