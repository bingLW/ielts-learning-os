# v2.4.1 用户操作说明：AI 初始诊断与智能定级

入口：左侧/底部导航「AI 初始诊断」，或直接访问 `/diagnostics`。

## 1. 开始前

1. 选择学习目标（通用英语、雅思、英语媒介学习等），可多选；
2. 可选填考试类型、过去教材、使用频率、每周可投入分钟数与主观强弱项；
3. 主观强弱项只作对照，不会直接变成等级；
4. 如需口语录音，勾选录音同意；不同意时仍可用文字完成口语题；
5. 如需 AI 评估开放任务，勾选外部 AI 同意；未启用外部 AI 时，口语/写作会保持「待评估」。

点击「开始诊断」后进入会话页。预计 2–3 个时段、共 40–60 分钟，可随时暂停。

## 2. 作答

- 页面顶部显示：状态、已完成数量、队列剩余、计时与暂停按钮；
- **听力**：点「播放录音」使用浏览器语音合成，首轮不显示文本；设备无法播放时点「标记技术无效」；
- **选择题/填空题**：直接选择或输入，点「提交此题」；
- **口语/写作（开放任务）**：页面会先展示评分维度（rubric），再输入文字；口语可录音（上限约 90 秒 / 1.6MB），也可只用文字；
- **技术无效**：录音失败、音频损坏、环境噪声导致无法完成时使用。该次尝试不计分、不产生证据，并会重新排队；
- **暂停/继续**：暂停后作答与录音都会保存，刷新或稍后回来可继续；
- **EMLR（可选）**：若开始前勾选，会追加一道英语媒介学习任务；它只作准备度参考，不标成 CEFR 等级。

## 3. 生成报告

队列完成后，点「生成能力画像与报告」。报告包括：

- 四项核心技能：Listening / Reading / Speaking / Writing，分别给出等级或范围、置信度、证据数量、覆盖度、局限；
- 辅助画像：Grammar / Vocabulary / Sentence Structure（以及可选 EMLR），不作为第 5–7 项官方能力；
- 摘要、主要优势、优先缺口、补测建议、局限与免责声明；
- 证据列表：每道题的原始作答、判分/评分状态与分数，可追溯到题库题号；
- 学习计划草案：7 天启动、30 天第一阶段、90 天方向。

**注意**：

- 报告是 AI 辅助 CEFR 估计，不是官方认证，也不预测 IELTS 分数；
- 四项技能不取平均；低置信度时只给范围；
- 未启用外部 AI 时，口语/写作显示「暂不能判断」，报告标为「暂定」，请先补测；
- 证据不足的技能会显示「暂不能判断」，不会强行定级。

## 4. 确认计划

1. 在报告页「学习计划草案」中按需修改每项任务的分钟数；
2. 点「确认并启用计划草案」；
3. 系统只把草案标记为 `ACTIVE`，**不会自动创建今日任务**；请到 `/plan` 手动把任务排入当天计划。

## 5. 复核、补测与删除

- **申请复核**：在报告页填写原因（如录音失败、题目歧义），提交复核请求；
- **发起补测**：创建新会话与新报告，旧报告保留，不会被覆盖；
- **删除本次诊断**：同时删除本轮作答、录音、写作原文、画像快照、报告、计划草案与本轮证据；其他历史诊断不受影响；
- 删除后如需重新建立基线，可再次点击「开始诊断」。

## 6. 常见问题

| 问题 | 说明 |
| --- | --- |
| 为什么口语/写作没有等级？ | 未启用外部 AI 时不会用模拟结果定级；可申请人工复核、启用外部 AI 后补测，或先用文字完成并等待复核 |
| 为什么听力没有声音？ | 浏览器需支持 SpeechSynthesis；不支持或设备静音时可标记技术无效，稍后重测 |
| 为什么报告是「暂定」？ | 存在待评估的开放任务、技能样本不足或置信度低；补测后可生成新的正式报告 |
| 补测会覆盖旧报告吗？ | 不会。每个会话独立保留报告，新报告不覆盖旧报告 |
| 确认计划后为什么今日计划没变？ | 设计如此：确认只激活草案，不自动创建 `PlanTask`；需到计划页手动排入 |
| 删除会话会影响历史证据吗？ | 只删除本轮证据；其他轮次与其他模块的证据不受影响 |
