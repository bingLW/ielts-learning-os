# v2.4 实施计划

## Phase 0：盘点（已完成）

- `docs/16-v2.4-gap-analysis.md`
- `main` 已包含 v2.3（`ce4d198`）

## Phase 1：AI Engine Foundation

1. Prisma 9 张新表 + `EvidenceRecord.aiSessionId`；`scripts/migrations/v2.4.mjs`。
2. `lib/ai/provider.ts`：Mock + OpenAI 兼容；超时/错误归一化。
3. `lib/ai/config.ts`：环境变量与模型/预算读取。
4. `lib/ai/prompts.ts`：7 个初始模板 + `ensurePromptRegistry()`。
5. `lib/ai/structured.ts`：6 个 zod Schema + JSON 提取。
6. `lib/ai/privacy.ts`：脱敏。
7. `lib/ai/meter.ts`：成本估算、预算判断。
8. `lib/ai/context.ts`：上下文构建（限额 + 纯函数）。
9. `lib/ai/state.ts`：状态机与不变量（纯函数）。
10. `lib/ai/orchestrator.ts`：调用、重试、幂等、日志。

## Phase 2：会话与 Tutor/Socratic

1. `lib/actions/tutor.ts`：开始会话、Baseline、诊断、提示、讲解。
2. `/coach/ai` 首页、`/coach/ai/[id]` 工作台。
3. 提示分级记录、暂停/继续/取消。

## Phase 3：Error & Drill & Retest

1. Drill 生成与练习提交。
2. Immediate Retest → Evidence（AI 辅助评估）。
3. Delayed/Applied/Transfer 排期（复用 `RetestSchedule`）。
4. 错误候选 → 用户确认后写 `Mistake`。
5. Evidence Review 页面。

## Phase 4：Examiner/Reviewer 与治理

1. Examiner 模式（无提示、Rubric、非官方声明）。
2. Reviewer（平行任务）。
3. Admin：模型、Prompt 版本、外部 AI 开关、预算。
4. Usage Dashboard：调用、Token、成本、错误率。
5. 反馈标记、导出、删除。

## Phase 5：测试与交付

1. Vitest：状态机、Schema、成本、脱敏、上下文限额、Mock Provider、幂等键。
2. E2E `scripts/e2e-v24.mts`：Mock 全链路（会话→Baseline→诊断→提示→练习→复测→排期→证据→删除不删证据）。
3. `typecheck`、`typecheck:test`、全量 vitest、E2E v2.1–v2.4、`next build`。
4. 备份 → 迁移 → 演练 → 回滚验证。
5. README、`.env.example`、测试报告、用户指南。
6. 提交并推送 `main`。

## 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 无真实 Key，不能验证外部 Provider | 接口与请求体单测；Mock 全链路通过；文档写清验证边界 |
| AI 输出不稳定 | 严格 Schema + 单次重试 + 可读失败 |
| 状态机被绕过 | Action 层与纯函数双重校验 |
| 预算误判 | 成本为估算值，界面标注；预算只做拦截，不改学习数据 |
| 页面状态多 | 统一 Toast + 空/错/加载态；失败保留草稿 |
