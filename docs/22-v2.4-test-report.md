## 3. 端到端验收

```bash
npm run test:e2e
```

真实结果：

| 套件 | 命令 | 结果 |
| --- | --- | --- |
| v2.1 回归 | `npm run test:e2e:v21` | 31 通过 / 0 失败 |
| v2.2 证据域全链路 | `npm run test:e2e:v22` | 37 通过 / 0 失败 |
| v2.3 TypeWords 集成 | `npm run test:e2e:v23` | 40 通过 / 0 失败 |
| v2.4 AI Coach 集成 | `npm run test:e2e:v24` | 3 通过 / 0 失败 |

`test:e2e:v24` 实际执行的断言链：

1. Prompt Registry 初始化幂等；
2. 以 Mock Provider 创建会话并生成任务；
3. 未提交基线时拒绝诊断与提示；
4. 保存基线并写入 BASELINE 证据；
5. 相同 `clientRequestId` 重放返回同一轮次；重复基线返回 CONFLICT；
6. 诊断 → 提示跳级被拒 → 第 1/2 级不含答案 → 讲解 → 生成练习；
7. 查询层在会话未完成时隐藏练习答案，且返回的 `session` 不携带原始 `turns`；
8. 原始基线文本在 AI 反馈后逐字不变；
9. 即时复测生成 A0、`assessorType='AI'` 的独立证据，并结清基线排期中的即时复测待办；
10. 复测重放幂等；
11. 会话完成后练习答案才可见；
12. 延迟复测排期成功，状态变为 `DELAYED_RETEST_SCHEDULED`；
13. 有帮助/不准确反馈落库；
14. 诊断提升为错题（Mistake 计数 +1）；
15. 删除会话后 2 条证据保留且 `aiSessionId` 置空，待办排期不被误删；
16. 预算置 0 后调用返回 `BUDGET_EXCEEDED`，只写 1 条 BLOCKED 日志，不生成讲解轮次。

测试全程复制 `prisma/dev.db` 到临时目录，通过 `process.env.DATABASE_URL` 指向副本，真实库未被写入。

## 7. 本轮发现并修复的问题

| 编号 | 问题 | 风险 | 修复 |
| --- | --- | --- | --- |
| F1 | `getAiSessionDetail` 直接返回含原始 `turns` 的 session 对象 | 未完成会话的练习答案可能随会话对象到达客户端 | 解构剔除 `turns`，只返回 `sessionSummary`；并为练习结构化内容做未完成态脱敏 |
| F2 | AI 即时复测未结清基线排期中的即时复测待办 | `/retest` 出现重复待办 | 在复测事务内查找并置为 DONE，关联新证据 |
| F3 | `render.test.ts` 未传提示级别 | 测试断言与实际渲染级别不一致 | 显式传入 `hintLevel: 2` |
