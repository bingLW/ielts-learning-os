## 1. 本阶段实际改动

1. `src/lib/services/planBuild.ts`：日/周 GENERATE 预览读取逾期任务并生成 PROMOTE / DEMOTE / BACKLOG / ABANDON 裁决；token 纳入完整逾期任务指纹；零写预览固定关闭 AI。
2. `src/lib/actions/planner.ts`：确认时先校验预览库存与 token，再在同一事务内应用 carryover、写入新任务和版本头；MONTH / CYCLE 的库存校验覆盖完整 horizon，而不是只检查基准日。
3. `src/lib/services/carryoverApply.ts`：按任务 ID 和状态守卫执行四类裁决；PROMOTE / DEMOTE 只滚入剩余分钟，BACKLOG 写 DEFERRED，ABANDON 写 CANCELLED 并保留原因；不物理删除任务或历史计时段。
4. `src/lib/services/replanPreview.ts` / `src/lib/domain/replan.ts`：自动锁定本周期滚入任务；重排预算同时计入已完成实际分钟、未开始计划分钟和不挂任务的学习净分钟，不重复扣减滚存前历史实际分钟。
5. `src/lib/services/planInventory.ts` / `src/lib/services/planWrite.ts`：预览、确认和统一写入者共用有效任务集合与预算占用口径；DONE / PARTIAL 按实际分钟占用，其他有效任务按实际与计划的较大值占用；历史版本 `taskIds` 不再次计入预算。
6. `src/lib/actions/planner.ts`：replan 事务冲突 P2002 / P2028 统一转为 `CONFLICT`，不把数据库冲突暴露成 500。
7. `src/lib/queries/planner.ts` / 解释 UI：版本任务集合回读 `afterSnapshot.taskIds`；carryover 裁决、原计划、实际、剩余分钟和最终去向按写出时快照展示，不重算。
8. `src/components/planner/build/CarryoverPanel.tsx` / `DraftActions.tsx`：预览展示四类裁决摘要与逐条依据；说明预览不写计划、不调用 AI。
9. `src/lib/actions/materialPack.ts` / `src/lib/services/planWrite.ts`：材料草案确认改为单事务批量写入，按日校验“已有任务占用 + 本批新增”；窗口外日期返回 `VALIDATION`，预算失败与 P2002 / P2028 整批回滚，成功后按 origin 写 `MANUAL_ADJUST` 版本并回读全部有效任务。
10. `src/lib/materials/__tests__/materialPack.integration.test.ts`：新增已有任务占用、窗口边界、多日期任一日失败整批回滚、预算恢复后每日一个版本审计的回归；Q6 返回键集合与预算闸门调用次数回归保持不变。
