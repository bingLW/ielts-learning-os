# v2.6 Changelog

## v2.6.0 — Smart Learning Materials（智能学习材料）

### 新增功能

- **材料导入**：TXT / Markdown / HTML / 文本型 PDF / DOCX + 粘贴摘录；内容嗅探（扩展名/声明 MIME/真实字节三向一致）、sha256 去重（「打开已有 / 另存副本」）、来源与授权登记（七类来源，`unknown`/`licensed_subscription` 导出常驻禁用并留痕）。
- **处理管线**：校验 → 解析 → 规范化 → AI 分析 → 生成练习，单机串行 tick + 3s 轮询，乐观锁并发控制，失败可重试（复用已解析结果，不重复计费）。
- **Reader**：原文 / 词汇辅助双模式；原文区在查询层即 return，**永不出现 AI 文本**；疑似注入文本警示条。
- **AI 分析审核**：逐条采纳/修改采纳/拒绝 + 批量；「查看依据」跳原文高亮；全部裁决后转可用。
- **练习生成与作答**：客观题唯一答案 + 依据可核验；未审核题进正式测评被 `materialExerciseGate` 结构性阻断；退役题不进新练习集、历史作答保留。
- **词汇候选与同步**：从已审核抽取结果物化候选 → 审核 → 同步进主库（已存在只加来源）；失败可重试。
- **材料包 + 任务草案**：引用式聚合（不复制正文）；草案按未来 7 天预算跨日拆分、超预算说明理由；确认前不写 `PlanTask`（复用 `createPlanTaskAction`）。

### 数据模型

- 新增 **17 张材料域表**，全库 93 → **110 表**。
- 迁移 `scripts/migrations/v2.6.mjs`（纯加法、单事务、幂等、checksum 校验），`AppMigration` 登记 v2.6。

### 关键设计决策（返工记录）

1. **`partial` 续跑不重开同一个 job**：AI 额度触顶后 `partial` 是终态语义；续跑改为「新开一次运行 + 跳过已有 `ExtractionResult` 的 chunk」，总调用量由文档规模决定，成本上限重新成为真上限。否决了按轮放大配额（`aiRounds`）的方案。
2. **补占位 `generating` 阶段**：`analyzing` 收尾进入 `generating`，而真实生成器在 T11 才接入；没有占位会导致材料永远到不了 `review_required`（`stage_not_registered`）。
3. **`review_required` 之后 tick 停手**：新增 `awaiting_review` 早返回，避免待审核态被轮询反复重跑。
4. **历史归一化键回退**：`normalizeLemma` 原地扩展 4 个折叠（NFD→NFC、零宽、全角、弯引号）后，主库旧键可能漂移；同步时按原词形兜底匹配，只加来源、不重建词条、不回写键。

### 修复的缺陷（开发期发现并修复）

- 材料级 `aiCallCount/estimatedCostUsd` 从未被写入 → `applyOutcome` 同事务累加。
- `cancelMaterialJobAction` 在待审核态误报 `CONFLICT` → 非可取消态直接返回当前状态。
- 删除材料未清理 `VocabularyItemSource` 归属行 → 补删，只删归属行、不删词条。
- `mock.ts` 硬编码 `source_chunk_seq: 1` → 从 `materialChunksBlock` 解析真实序号。
