## 3. 浏览器冒烟（实际执行）

- 打开 `/diagnostics`，确认免责声明、隐私说明与同意项可见；
- 点击「开始诊断」成功创建会话，首题 `L-DETAIL-A2`；
- 选择 B 提交，得分 2/2，下一题变为难度 3 的 `L-GIST-B1`，证明自适应升档生效；
- 暂停后刷新页面，状态仍为「已暂停」，已完成记录保留；恢复后继续；
- 完成全部队列（含口语/写作开放任务）：开放任务显示「待人工/补测」，提示“未启用外部 AI 时不会用模拟结果定级”；
- 生成报告：显示「暂定（证据不足，需补测）」、四技能分别呈现、不取平均、证据列表与补测建议；
- 修改 7 天计划中一项分钟数为 25，点击确认；提示“已标记为 ACTIVE，不会自动创建今日任务”，数据库 `PlanTask` 仍为 8 行，`tasksJson` 保存 25；
- 点击「发起补测」创建新会话，旧报告仍可访问；
- 在旧报告页确认删除：会话、报告、计划草案与本轮证据全部删除，历史 `PlanTask` 不受影响。

> 浏览器为后台标签页时，Next.js 流式渲染会暂停揭示（`document.visibilityState=hidden`），页面显示“正在加载数据”；将标签页切到前台或触发 `visibilitychange` 后正常渲染。这是既有运行环境行为，不是 v2.4.1 页面缺陷。

## 4. 验证期间发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 选择题只取首字符判分，输入选项文本无法识别 | 先比对完整选项键，再按归一化后的选项文本比对；不做模糊匹配 |
| 自适应平行题插入下标为 1，下一题仍是原队列题 | 插入队首，保证下一题立即验证难度判断 |
| 幂等去重位置在队列/顺序校验之后，重放请求被拒 | 幂等检查提前到题目加载后，重复请求直接返回成功 |
| “每技能最多 2 题”按单题作答次数计算，可连锁加题 | 改为按会话内该技能的有效作答数统计（排除 `INVALID`） |
| Prompt Key 不符合既有 `ai.*.v1` 约定 | 诊断提示词统一为 `ai.diag.*.v1`，并放宽校验为多段命名空间 |

## 5. 残余风险与限制

- 未启用外部 AI 时，口语/写作无等级，只能人工复核或补测；这是有意设计。
- 浏览器不支持 SpeechSynthesis 时，听力题需标记技术无效。
- 录音以 data URL 存 SQLite，上限约 1.6MB/90 秒。
- `AIEngineSetting` 的既有 schema drift 未处理，与本版本无关。
