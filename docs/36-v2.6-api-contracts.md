| --- | --- |
| `POST /api/upload-material` | 上传原文（200/400/413） |

## 5. 关键不变量（联调勿破坏）

- 原文模式不读 `ExtractionResult`/`VocabularyCandidate`；
- 未审核题（`draft/needs_review`）`canEnterPlacement()===false`；
- 词条同步只加来源、不覆盖主库；`BASELINE` 证据恒禁；
- 草案确认前不写 `PlanTask`；材料包只存 `refId` 不复制正文。
