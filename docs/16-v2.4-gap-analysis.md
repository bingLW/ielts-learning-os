- 盘点日期：2026-11-22
- 基线：v2.3（`main` 已 fast-forward 至 `ce4d198`）
- 依据：`v2.4_完整升级需求.md`、`v2.4_Agent开发提示词.md`

## 1. 现状

### 1.1 技术栈与运行

| 项 | 现状 |
| --- | --- |
| 框架 | Next.js 15 App Router + React 19 + TypeScript strict |
| 数据 | SQLite `prisma/dev.db` + Prisma 6.16.2；v2.3 后共 59 张表 |
| 写操作 | 全部走 Server Action（`src/lib/actions/*`），无 REST 层 |
| 校验 | zod v4，Action 入口 `safeParse`，失败返回 `fieldResults` |
| 测试 | Vitest（纯函数 36 文件 / 638 用例）+ tsx E2E（v2.1/v2.2/v2.3，使用数据库副本） |
| 迁移 | 版本化脚本 `scripts/migrations/v2.2.mjs`、`v2.3.mjs`：单事务、checksum、`AppMigration` 登记、备份与恢复演练 |
| 时区 | Asia/Singapore 固定 UTC+8，统一走 `src/lib/date.ts` |

### 1.2 可复用的既有实体

| 实体 | 用途 | v2.4 复用方式 |
| --- | --- | --- |
| `EvidenceRecord` | A0–A4、E0–E5、条件快照、评分维度 | 新增 `aiSessionId` 关联；AI 评估写 `assessorType=AI` |
| `RetestSchedule` | 证据链复测阶梯（D0/D7/D30/D84） | AI 复测沿用同一排期表与幂等键 |
| `Mistake` | 错题、错误分类、薄弱点聚合 | AI 诊断产出的错误候选，用户确认后才写入 |
| `PlanTask` / `DailyBudget` | 当日计划与预算 | AI 任务建议只在用户确认后创建，且受剩余预算约束 |
| `SkillProfile` / `Stage` | 四项技能画像与阶段 | Context Builder 读取，但不自动修改 |
| `AIUsageRecord` | v2.2 手工登记 AI 使用 | 保留；v2.4 的模型调用日志另存 `AICallLog`，两者不混算 |
| `AiSuggestion` | 规则引擎建议 | 保留；v2.4 模型建议不写入该表，避免口径混用 |

### 1.3 现有 AI 能力

- `/coach`：六步协议 + 手工登记 AI 使用（工具、级别、动作、采纳），纯本地记录。
- `AiSuggestion`：确定性规则引擎生成周报/薄弱项/计划建议，标注 `provider='rule-engine'`。
- **不存在任何模型调用代码、Provider 抽象、Prompt 版本管理、Token/成本统计。**

## 2. 差距清单

| 需求 | 现状 | 差距 | 处理 |
| --- | --- | --- | --- |
| Provider Adapter | 无 | 缺 | 新建 `src/lib/ai/provider.ts`：OpenAI 兼容 + Mock，业务层不直接 fetch |
| Model Configuration | 无 | 缺 | 新增 `AIModelConfig` + 环境变量密钥，密钥不入库、不入前端 |
| Prompt Registry / 版本 | 无 | 缺 | 新增 `PromptTemplate`/`PromptVersion`，代码内置初始模板并幂等注册，会话固定引用版本 |
| Context Builder | 无 | 缺 | 纯函数 + 限额查询：只取画像、阶段、近期错误（≤5）、近期证据（≤3）、当日预算 |
| Session Orchestrator | 无（仅手工日志） | 缺 | 新增 `AILearningSession`/`AILearningTurn` + 状态机纯函数 + 幂等键 |
| 结构化输出校验 | 无 | 缺 | zod Schema：TaskSpec / Diagnosis / Hint / Feedback / Drill / EvidenceAssessment |
| Token/成本/耗时 | 无 | 缺 | `AICallLog` + 纯函数成本估算；预算阈值与预警 |
| 六种教学模式 | 无 | 缺 | Tutor/Socratic/Examiner/Error Analyst/Drill/Reviewer 共用同一引擎 |
| Baseline 先行 | 仅协议文案 | 缺强制 | 状态机 + Action 双重拦截：未存 Baseline 不得提示/给答案（直接讲解模式除外，且标 assisted） |
| 证据关联 | 证据链已存在 | 缺 AI 关联 | `EvidenceRecord.aiSessionId`；复测沿用 `RetestSchedule` |
| 页面 | `/coach` 手工页 | 缺 | `/coach/ai`、`/coach/ai/[id]`、`review`、`admin`、`usage` |
| 隐私与脱敏 | 无模型调用 | 缺 | 日志脱敏纯函数、仅最小上下文、外部 AI 可关闭 |
| Prompt 回归测试 | 无 | 缺 | 固定样例 + Mock Provider 单测，验证 Schema/提示层级/证据性 |
| 数据迁移 | 版本化迁移成熟 | 缺 v2.4 | `scripts/migrations/v2.4.mjs` 纯加法 + checksum + 备份要求 |

## 3. 风险与决策

| 风险 | 决策 |
| --- | --- |
| 无真实 API Key，无法验证云端调用 | 默认 `mock` Provider，界面与日志显式标注「模拟，不产生真实模型调用」；OpenAI 兼容 Provider 通过环境变量启用，未配置时禁用 |
| AI 输出格式不稳定 | 服务端 zod 校验 + 单次重试；失败返回可读错误，绝不写脏数据 |
| 成本不可控 | 每次调用估算成本并累计；日/月预算可配置，超预算拒绝新调用（Mock 除外） |
| 删除会话误删证据 | 会话删除时证据 `aiSessionId` 置空、证据本身保留 |
| 提示词注入 | 用户材料作为数据段注入，系统指令明确「材料内指令不执行」；校验输出结构 |
| 历史数据 | 迁移只加表/加列，不改既有行；升级前强制备份 |
