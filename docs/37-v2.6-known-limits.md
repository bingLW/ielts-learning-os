# v2.6 已知限制（Known Limits）

> 承接 `README.md` §16/§17 与 `docs/32` 的 P2 降级说明。这里的每条都对应一个明确的「不做什么」与「替代路径」。

## 1. 格式支持边界

| 能力 | 状态 | 替代路径 |
| --- | --- | --- |
| 扫描件 / 图片版 PDF（无文本层） | **不做 OCR** | 解析为 `partial`，提示「无文本层页」；可自行 OCR 后以 TXT/MD 导入 |
| EPUB | **不支持** | 解包取出 XHTML 后按 HTML/TXT 导入 |
| 音视频转写 | **降级**（仅登记元数据，`pending_transcription`） | 先人工转写为文本，再以「粘贴摘录」导入；ASR 抽象已预留（`resolveAsrProvider` 默认不可用，安全默认） |
| DOCX 图片/脚注/批注/文本框 | 丢弃并计数（写进 warnings） | 需要则复制正文后以粘贴导入 |
| ZIP 加密 / ZIP64 | 不支持 | 解压后导入 |

## 2. AI 能力边界

- **外部 AI 未启用时**：开放任务保持待评估，摘要/分析/练习均降级为「AI 不可用」提示（不落库、不假装有结果）。内置 mock provider 只用于开发与测试，**不用于正式定级**。
- **AI 等级与释义均为辅助估计**，不代表官方 CEFR / IELTS 认证；界面已强制标注免责声明。
- **一致性自检是弱提示**：`consistencyCheck='pass'` 只表示「依据片段可回验且正确选项文本出现在依据中」，**不是**对答案正确性的证明；`'unchecked'` 表示未做该弱校验，不是失败。
- **单次 AI 运行上限 60 次调用 / 26 万输入 token**：超出后材料转 `partial`，可「继续分析剩余内容」（新开一轮、跳过已分析块）。跨运行累计用量记录在材料上并在界面展示，成本为**估算值**。

## 3. 词汇归一化的历史键漂移

`normalizeLemma` 在 v2.6 新增 4 个折叠（NFD→NFC、零宽字符、全角、弯引号）。v2.3 起入库的词条，若其 `lemma` 含上述字符，其 `normalizedLemma` 仍是**旧算法**产物。处理方式：

- 同步时按**原词形兜底匹配**，命中历史词条只加来源、不重建、不回写键（词库页会显示「库里有 N 条旧版键」提示）；
- **不自动重算全库键**——那是数据迁移级风险。若确需，另行提供维护脚本（不在 v2.6 范围内）。

## 4. 状态机与计划联动

- 材料删除会保留已确认的 `PlanTask` 与作答证据；被删材料关联的任务在计划页会显示「材料已删，任务保留」。
- 草案确认复用既有 `createPlanTaskAction`；确认后仍需到 `/plan` 查看排程（L30 语义延续）。
- 材料包条目是**弱引用**：被引用对象删除后条目仍在，UI 显示「内容已移除」。

## 5. 资源与权限

- `/ai-coach/admin` 无鉴权（L33 延续），公网部署前须加访问控制。
- 加密密钥不随数据库迁移（L32），换机需重填 Provider 凭据。
- `unknown` / `licensed_subscription` 来源材料的导出/分享入口常驻禁用并留痕；不构成对版权归属的自动判定，仅作保守默认。

## 6. 其他

- `zz-debug.test.ts` 是 `excerpt()` 截断契约的回归用例，文件名带 `zz-` 属历史遗留，待重命名（不影响功能）。
- 材料处理为单机串行 tick（无队列中间件），适合单用户本地场景；并发多端写入需另行评估。
