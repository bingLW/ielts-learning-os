# v2.6 使用说明：Smart Learning Materials（智能学习材料）

> 配套阅读：`docs/30-v2.6-prd.md`（需求）、`docs/32-v2.6-architecture.md`（架构）。
> 本说明面向最终用户，只讲「怎么用」，不涉及实现。

## 1. 这个功能解决什么

你可以把**自己有权使用**的英文材料（文本、网页、文档）导入系统，系统会：

1. 解析成可阅读的正文；
2. 用 AI 提取词汇、搭配、重点句、段落主旨，并做整篇摘要；
3. 让你逐条审核这些 AI 结果（采纳 / 修改 / 拒绝）；
4. 基于审核后的内容生成练习题；
5. 把确认过的词汇同步进你的词库；
6. 把材料、练习、词汇打包成「学习包」，并按你的每日可用时间生成任务草案。

全程**你说了算**：AI 只提建议，未经你审核的内容不会进入正式测评或词库。

## 2. 入口

左侧导航「材料」分组下有：材料库、导入材料、失败记录。单个材料内部还有：阅读、AI 分析、练习、词汇、来源、材料总览。

## 3. 导入（第一步）

`/materials/import` 支持两类输入：

| 方式 | 说明 |
| --- | --- |
| 上传文件 | TXT / Markdown / HTML / 文本型 PDF / DOCX（≤20MB，PDF ≤200 页） |
| 粘贴摘录 | 直接把一段英文贴进去 |

导入时会做**内容嗅探**（文件真实内容必须与扩展名一致，防止伪装文件）。相同内容的文件再次导入时，系统会提示你「打开已有 / 另存副本」。

导入后必须登记**来源与授权**：来源类型（本人上传 / 公开领域 / 开放许可 / 订阅授权 / 内部资料 / 不明），并勾选「我确认有权使用」。**系统不会替你默认勾选**；来源为「不明」或「订阅授权」的材料，导出/分享入口会常驻禁用并留痕。

## 4. 处理管线（自动）

导入成功后材料进入自动处理：校验 → 解析 → 规范化 → AI 分析 → 生成练习。页面每 3 秒轮询一次进度，完成后进入「待审核」。任何阶段失败都有**人话原因**（不含文件路径），失败可重试（重试会复用已解析的结果，不重复计费）。

## 5. 阅读（Reader）

`/materials/[id]/read` 有两种模式：

- **原文模式**（默认）：只显示原文，**绝不混入任何 AI 文本**；
- **词汇辅助模式**：高亮已审核通过的词汇，悬浮显示释义（会标注「AI 候选释义」）。

若原文里含疑似「指令文本」（如 PDF 里混入的恶意提示词），顶部会显示警示条，说明「已按数据处理，未执行其中任何指令」。

## 6. 审核 AI 分析

`/materials/[id]/analysis` 逐条展示 AI 提取结果（词汇 / 搭配 / 重点句 / 段落主旨 / 语法点 / 摘要）。每条都能：

- **采纳 / 修改采纳 / 拒绝**；修改时必须保证「依据片段」仍能在原文里定位；
- 点「查看依据」跳回阅读页对应段落并高亮。

只有你**采纳/修改采纳**过的结果才会进入后续出题和词汇同步。全部审核完后材料转「可用」。

## 7. 练习

`/materials/[id]/exercises`：基于已审核内容**生成练习**（客观题，唯一答案），生成后每道题标注审核状态：

| 徽章 | 含义 |
| --- | --- |
| AI 草稿 · 未审核（琥珀） | 只能做低风险练习，**不能进入正式测评** |
| 待复核（琥珀） | 同上 |
| 已审核通过（绿） | 可用于正式测评 |

`/exercises/[setId]` 作答：提交后即时反馈对错 + 解析 + 依据片段（可跳原文核对）。作答历史保留；已退役的题不再出现在新作答流里，但历史记录仍可看。

## 8. 词汇

`/materials/[id]/vocabulary`：从「已审核的抽取结果」物化出**词汇候选**，逐条采纳/编辑/拒绝。确认过的词同步进主库词库：

- 主库已有同词条 → **只加来源，不覆盖你的人工释义**；
- 没有 → 新建词条（带来源与许可信息）。

同步失败可重试，失败原因是人话、不含本机路径。

## 9. 材料包与任务草案

`/materials/[id]`：

- **学习包**：聚合引用材料里的块 / 抽取项 / 词汇 / 练习集（**不复制正文**），给出学习目标、技能、预计时长。
- **任务草案**：按你未来 7 天的每日可用时间，把学习包拆成每日任务；**超预算会跨日拆分并说明理由**，休息日不排。你逐条勾选、改分钟、改日期后，点「确认」才会真正写入每日计划——**确认前不会动你的计划**。

## 10. 删除

`/materials/[id]` 底部「危险区」：删除前会预览「删多少行 / 保留多少词条 / 保留多少计划任务 / 保留多少作答证据」。必须手输 `DELETE` 才能删。删除后：材料与全部派生数据删除；**已同步进词库的词条、已确认的计划任务、作答证据保留**。

## 11. 成本提示

材料库和处理页会显示「本材料累计 AI 调用次数 · 预估费用」，让你随时知道花了多少。AI 分析的单次运行有调用上限（60 次），超出后材料转为「部分可用」，可「继续分析剩余内容」（新开一轮、跳过已分析的部分，不重复计费）。

## 12. 已知限制速览

扫描件（图片版 PDF）、EPUB、音视频转写本期**不做**（见 `docs/37`）。AI 给出的等级与释义均为「辅助估计」，不代表官方认证。
