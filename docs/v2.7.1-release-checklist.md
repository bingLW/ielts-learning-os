## 3. 真实库事故披露

一次隔离浏览器夹具命令漏传 `DATABASE_URL`，Prisma 对真实 `prisma/dev.db` 执行了 `db push`。该操作违反项目约束，尚未关闭。

可核实事实：

- 误操作前 SHA-256：`36622ec6602e86128de5d1f98d6fb90bbebb005672063ffce84bf216e210c747`
- 误操作后 SHA-256：`1b7d888e2b3eeb587e02ed2caa622ddd6eecdf8eff7d1c369d5e45a8386772d9`
- `PRAGMA schema_version`：1 → 131
- 误操作后 `PRAGMA integrity_check=ok`
- 事故后备份：`backups/dev-20261126-214859.db`
- `backups/dev-20261123-220358.db` 缺后续 schema，不能安全恢复覆盖
- 没有误操作前完整副本，不能证明逐字节恢复

当前措施：保留事故后快照；禁止对真实库执行任何写命令；测试、迁移、恢复和浏览器服务只使用显式 `/tmp` 隔离库。

关闭条件：取得可验证的事故前完整备份或由数据所有者明确接受不可逆差异，并对当前真实库副本完成版本化迁移、integrity/外键/行数核对和恢复回滚演练。未满足前 P0-5 与 AC-08 不得通过。

## 4. 再次放行前必须执行的门禁

以下步骤是发布操作要求，不是把当前未完成工作转嫁给用户。当前环境缺少真实库放行授权与凭据，因此保持阻断。

### 4.1 数据与迁移

1. 停止应用，确认没有进程写数据库。
2. 对当前库执行一致性备份，覆盖 DB 与 uploads；不得用 `cp prisma/dev.db` 代替 SQLite `.backup`。
3. 只在 `/tmp` 副本上执行：

   ```bash
   node scripts/migrations/v2.7.1.mjs --db /tmp/<isolated-copy>.db --dry-run
   node scripts/migrations/v2.7.1.mjs --db /tmp/<isolated-copy>.db
   node scripts/migrations/v2.7.1.mjs --db /tmp/<isolated-copy>.db
   ```

4. 核对 9 列、2 索引、AppMigration checksum、全表行数、integrity 和外键。
5. 从迁移前自动备份恢复至 `/tmp`，核对 dump/行数与源基线一致。
6. 真实库迁移必须另行取得明确授权；未授权不得执行。

构建必须与开发服务、typecheck、全量测试互斥。Provider 未显式 opt-in 时保持 `NOT_RUN`，不得改写为 PASS。

### 4.3 浏览器门禁

使用显式 `DATABASE_URL=file:/tmp/ielts-browser-*.db`，至少补足：

- 全新安装产物首次打开与无基线展示。
- 诊断→报告→提案→预览→确认→执行记录→复测→周报完整链路。
- 预览后改预算的 `CONFLICT`。
- carryover Preview 零写、Confirm 单次写、重复 Confirm 幂等。
- DEMOTE、CYCLE、并发双提交。
- 上传/删除资产及 tombstone 展示。
- 导出、备份、恢复页面流程。

只有页面正文、AX 或截图可证明的结论才能记录；外部 Chrome 不支持 console API，不得声称 console 零错误。

### 4.4 Provider 门禁

真实调用必须同时满足：

- `AI_SMOKE_OPT_IN=1`
- `AI_SMOKE_CONSENT=1`
- 存在合法 API Key 与 Base URL
- 日/月预算为正数
- `DATABASE_URL` 指向 `/tmp` 隔离库
- 只发送合成写作提示，不发送用户作文、录音或文档正文

## 5. 回滚步骤

1. 停止应用。
2. 保留当前故障现场和日志，不覆盖现有库。
3. 校验备份 bundle 的整体 checksum、manifest、逐文件 checksum、迁移账本、SQLite integrity 和外键。
4. 默认恢复到 `/tmp` 新目录验证。
5. 需要覆盖恢复时，先保存 DB+uploads 安全网，再使用显式 `--overwrite` 和双重确认。
6. 验证失败时执行 `--rollback <SAFETY> --target <目标目录>`。
7. 恢复后重新执行 integrity、外键、关键表行数与uploads文件清单核对。

参考：`docs/48-v2.7-migration-guide.md`、`scripts/backup.sh`、`scripts/restore.sh`、`docs/v2.7.1-test-report.md`。

## 6. 当前明确不做的行为

- 不重建真实数据库，不删除历史计划、诊断、证据或词汇记录。
- 不把旧数据强行解释成新版本证据。
- 不把未知写成 0 或 1。
- 不把 AI 单次评估当作正式 CEFR/IELTS 成绩。
- 不自动激活计划或切换阶段。
- 不用 mock 冒充真实诊断或模型结果。
- 不为“全绿”跳过测试、降低断言或隐瞒未执行项。
