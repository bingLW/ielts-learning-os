# v2.4 服务接口契约

所有写操作均为 Server Action，统一返回 `ActionResult<T>`（`{ok:true,data}` 或 `{ok:false,code,error,fieldErrors?}`）。前端不接触 Provider 密钥。

## 1. 会话

### `startSessionAction(raw)`

```ts
{
  mode: 'TUTOR'|'SOCRATIC'|'EXAMINER'|'ERROR_ANALYST'|'DRILL'|'REVIEWER';
  skill: 'LISTENING'|'READING'|'SPEAKING'|'WRITING'|'GRAMMAR'|'VOCABULARY'|'INTEGRATED';
  objective: string;          // 1–500 字
  targetLevel?: 'A0'|'A1'|'A2'|'B1'|'B2'|'C1';
  allowedAids?: string[];     // DICTIONARY/TRANSLATION/NOTES/AI_HINT
  directTeaching?: boolean;   // 直接讲解模式：结果强制 assisted
  clientRequestId: string;
}
→ { sessionId: string; taskTurnId: string; providerMode: 'mock'|'external' }
```

副作用：创建会话与 TaskSpec 调用；失败时会话保留为 `failed`，可重试。

### `submitBaselineAction(raw)`

```ts
{ sessionId; text: string(1–20000); aidLevel?: 'A0'|'A1'|'A2'|'A3'|'A4'; minutesSpent?: number; clientRequestId }
→ { turnId; evidenceId }
```

约束：只允许 `TASK_PRESENTED`；写入不可修改的 Baseline Turn 与 `EvidenceRecord(BASELINE)`。

### `requestDiagnosisAction(raw)`

```ts
{ sessionId; clientRequestId }
→ { turnId; diagnosis: DiagnosisResult }
```

### `requestHintAction(raw)`

```ts
{ sessionId; level: 1|2|3; clientRequestId }
→ { turnId; hint: HintResult }
```

约束：必须先有 Baseline；等级逐级递增；1–2 级不得泄露答案。

### `requestTeachingAction(raw)`

```ts
{ sessionId; clientRequestId }
→ { turnId; feedback: FeedbackResult }
```

### `generateDrillAction(raw)`

```ts
{ sessionId; count?: 1–10; clientRequestId }
→ { turnId; drill: { items: { question: string; rubric: string; estimatedMinutes: number }[]; totalMinutes } }
```

答案与解析保存在服务端结构化载荷中；用户在提交练习前看不到。

### `submitImmediateRetestAction(raw)`

```ts
{ sessionId; text: string; clientRequestId }
→ { turnId; evidenceId; assessment: EvidenceAssessment }
```

先保存用户原始答案，再调用评估提示词；评估失败时答案仍保留。

### `scheduleDelayedRetestAction(raw)`

```ts
{ sessionId }
→ { created: number }   // DELAYED 7d / APPLIED 30d / TRANSFER 84d
```

### `pauseSessionAction` / `resumeSessionAction` / `cancelSessionAction` / `deleteSessionAction`

```ts
{ sessionId }
→ { status }
```

`deleteSessionAction` 不删除证据。

## 2. 反馈

### `markTurnFeedbackAction(raw)`

```ts
{ sessionId; turnId?: string; helpfulness: 'HELPFUL'|'UNHELPFUL'|'INACCURATE'; note?: string }
→ { id: string }
```

## 3. 错误候选（用户确认后入库）

### `promoteDiagnosisToMistakeAction(raw)`

```ts
{
  sessionId;
  knowledgePoint: string;
  originalQuestion: string;
  myAnswer: string;
  correctAnswer: string;
  errorCategory: 'RULE_NOT_UNDERSTOOD'|'MEMORY_CONFUSION'|'VOCAB_UNKNOWN'|'WORD_ORDER'|'CARELESS'|'OTHER';
}
→ { mistakeId: string }
```

只在用户显式提交表单后调用；AI 不会自动写入错题本。

## 4. 管理

| Action | 输入 | 说明 |
| --- | --- | --- |
| `updateEngineSettingAction` | `{ externalAiEnabled?, dailyBudgetUsd?, monthlyBudgetUsd?, warnPercent?, directTeachingDefault?, explainLanguage? }` | 外部 AI 默认关闭 |
| `setDefaultModelAction` | `{ modelConfigId }` | 切换默认模型（不影响既有会话） |
| `createPromptVersionAction` | `{ promptKey, systemTemplate, userTemplate }` | 追加新版本并发布；历史版本只读 |
| `exportSessionAction` | `{ sessionId }` | 返回 JSON 字符串供下载 |
| `retryFailedSessionAction` | `{ sessionId }` | 只允许 `failed` 会话 |

## 5. DTO（页面读取，`queries/tutor.ts`）

- `CoachHomeDto`：provider 状态、模型列表、最近会话（≤20）、当日/本月用量、预算预警。
- `SessionViewDto`：会话、任务、Turn 列表（用户答案/AI 结构化内容分字段）、提示使用情况、证据与复测、反馈标记。
- `UsageDashboardDto`：按日聚合的调用数、Token、成本、时延、错误率、各模式分布。
- `AdminDto`：模型配置、Prompt 模板与版本、引擎设置。

## 6. 错误码

沿用 `VALIDATION | NOT_FOUND | CONFLICT | PRECONDITION | INTERNAL`；新增业务语义在 `error` 文案中说明（如「外部 AI 未启用」「预算不足」「必须先保存 Baseline」）。
