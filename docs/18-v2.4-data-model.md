# v2.4 数据模型与迁移

## 1. 新增表（9 张）

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| `AIModelConfig` | provider, model, label, capabilitiesJson, active, isDefault, contextWindow, inputPricePerMtok, outputPricePerMtok, parametersJson | 模型能力与价格；密钥不入库 |

| `PromptVersion` | templateId, version, systemTemplate, userTemplate, inputSchemaJson, outputSchemaJson, status, testSamplesJson, checksum, createdAt, publishedAt | `(templateId,version)` 唯一；已发布不可覆盖 |
| `AILearningSession` | mode, skill, objective, status, promptTemplateKey, promptVersionId, modelConfigId, provider, model, baselineText, contextJson, taskSpecJson, rubricJson, directTeaching, startedAt, completedAt, estimatedCostUsd, inputTokens, outputTokens, totalLatencyMs, parentSessionId, failureReason | 会话主表 |
| `AILearningTurn` | sessionId, sequence, role, kind, contentText, structuredJson, aidLevel, promptVersionId, requestId, clientRequestId, latencyMs, inputTokens, outputTokens | 原始用户输入与 AI 输出分开存 role/kind；`(sessionId,clientRequestId)` 唯一 |
| `LearningTaskInstance` | sessionId, planTaskId, taskSpecJson, source, estimatedMinutes, difficulty, allowedAidsJson, status | 任务实例；可追溯到计划任务 |
| `AICallLog` | sessionId, provider, model, promptVersionId, requestId, latencyMs, inputTokens, outputTokens, estimatedCostUsd, status, errorCode, redactedMetadataJson | Token/成本/时延/错误 |
| `AISessionFeedback` | sessionId, turnId, helpfulness, note | 有帮助/不准确反馈 |
| `AIEngineSetting` | id('default'), externalAiEnabled, dailyBudgetUsd, monthlyBudgetUsd, warnPercent, directTeachingDefault, explainLanguage | 单行设置 |

## 2. 既有表变更

`EvidenceRecord` 新增：

- `aiSessionId TEXT NULL`
- 外键 `aiSessionId → AILearningSession(id) ON DELETE SET NULL`
- 索引 `[aiSessionId]`

只加列，不改既有列、不删除历史数据。

## 3. 迁移

```bash
bash scripts/backup.sh
node scripts/migrations/v2.4.mjs --db prisma/dev.db --dry-run
node scripts/migrations/v2.4.mjs --db prisma/dev.db
```

- 单事务：建表、建索引、ALTER 加列、种子（模型配置 2 行、设置 1 行）、`AppMigration(version='v2.4')`。
- 幂等：`CREATE TABLE/INDEX IF NOT EXISTS`、固定种子 id + `INSERT OR IGNORE`。
- checksum：与脚本内常量比对，同版本不同 checksum 拒绝执行。
- 前置检查：`integrity_check`、`foreign_key_check`、核心表行数快照写入 `backups/migrations/`。
- Prompt 模板不写 SQL：由运行时 `ensurePromptRegistry()` 幂等注册，便于代码评审。

## 4. 回滚

```bash
bash scripts/restore.sh backups/<升级前备份>
npm run db:generate
```

恢复只回退数据库；若需回退代码，`git revert` 对应提交。证据与会话表被丢弃，但升级前的既有学习数据不受影响。

## 5. 删除策略

| 对象 | 行为 |
| --- | --- |
| 删除 AI 会话 | 级联删除 Turn / LearningTaskInstance / Feedback；CallLog 保留但 `sessionId=NULL`；证据保留、`aiSessionId=NULL` |
| 删除证据 | 既有规则不变（归档而非物理删除） |
| 删除会话导出 | 支持 JSON 导出后再删除 |
