# IELTS Learning OS 使用手册（v2.3）

本手册面向日常使用者，覆盖当前 v2.3 的全部功能：v2.1 自适应计划、v2.2 证据驱动学习、v2.3 TypeWords 词汇引擎集成。

界面以中文为主；A0–A4、QUICK/STANDARD/FULL、CEFR、SUMMARY_ONLY 等专业术语保留英文原文。日期与时刻统一按 **Asia/Singapore（UTC+8）** 归属业务日。

---

## 1. 安装与启动

### 1.1 环境要求

| 项目 | 要求 |
| --- | --- |
| Node.js | ≥ 20（验证环境为 Node 22） |
| 包管理器 | npm（仓库含 `package-lock.json`，不要混用 pnpm/yarn） |
| 数据库 | SQLite 单文件 `prisma/dev.db`，无需安装数据库服务 |
| 端口 | 默认 3000 |

### 1.2 启动

```bash
npm run dev        # → http://localhost:3000
```

仓库是可直接运行的交付：依赖已安装、`prisma/dev.db` 已建库并写入种子数据。浏览器打开 `http://localhost:3000` 即可。

### 1.3 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器（热更新） |
| `npm run build` / `npm run start` | 生产构建 / 启动构建产物 |
| `npm test` | 纯函数单元测试（Vitest） |
| `npm run test:e2e` | v2.1 + v2.2 + v2.3 端到端验收（使用数据库副本，不改真实库） |
| `npm run typecheck` / `npm run typecheck:test` | 源码 / 测试文件类型检查 |
| `bash scripts/backup.sh` | 一致性备份（不强依赖 Node） |
| `bash scripts/restore.sh <备份文件>` | 从备份恢复（高风险，需二次确认） |
| `node scripts/migrations/v2.3.mjs --db prisma/dev.db --dry-run` | 只打印迁移 DDL |
| `node scripts/migrations/v2.3.mjs --db prisma/dev.db` | 执行 v2.3 迁移 |

> `npm run db:reset` 会**删库重建**，所有学习数据丢失；不要用它来处理启动报错。

## 2. 先建立概念地图

### 2.1 三条并行轨道（互不换算）

| 轨道 | 定位 | 判定依据 |
| --- | --- | --- |
| General English | 长期综合能力，目标 B2 左右 | 四技能 CEFR 评估 |
| IELTS Preparation | 阶段性考试，总分与单项可配置 | 正式/模考成绩 |
| English-mediated Learning | 用英语学法语等知识，跨技能应用 | 学习会话 + 英文产出 |

三条轨道分别统计、分别验收，系统**不合成「总能力分」**。阶段名称（阶段零 / A2 / B1 / IELTS）是个人路径标签，不是 CEFR 官方认证。

**四技能配比口径**：分母只含听力/阅读/口语/写作四项专项训练时间；词汇、语法、句子成分、复盘、泛听泛读属支持性时间，单独统计、不进分母。分母为 0 时占比显示 `—`，不是 0%。

### 2.2 三样不同的「学习」

| 名称 | 回答的问题 | 入口 | 会不会自动排期 |
| --- | --- | --- | --- |
| 学习记录（StudyRecord） | 今天练了什么、做了多少 | `/records` | 不会 |
| 知识型复习（ReviewTask） | 词汇/错题/语法点该复习了 | `/review`、`/mistakes` | 会（1/3/7/14 天） |
| 证据（EvidenceRecord） | 撤掉辅助后我到底能做到什么 | `/evidence` | 会（复测阶梯 D0/D7/D30/D84） |

两套排期互不复用状态：在复习中心完成词汇复习，不会让技能复测自动完成；反之亦然。

### 2.3 每日预算

- 在 `/settings` 设置每日可用分钟（15–240，可自定义）；默认计划按 240–300 分钟拆分到 9 个模块。
- `/plan` 按预算生成当日计划；单任务支持计时/暂停/完成，未完成任务顺延不超过 2 次。
- 当日预算 ≤15 分钟属于**维持性练习**，系统不要求证据链。
- 如果今天有到期复测，计划卡片会显示「含证据复测 X 分钟（已计入预算，不重复计时）」。

## 3. 每天怎么用（建议顺序）

1. **看计划**（`/plan`）：确认今日预算、模块分配与是否有到期复测。
2. **先做复测**（`/retest`）：按「逾期 → 今日到期 → 未来 7 天」顺序处理；复测必须 A0（无辅助）。
3. **按计划计时执行**：在 `/plan` 里对任务计时，暂停/完成都会落库；跨零点时长自动按自然日拆分。
4. **留原始样本**（`/evidence`）：点击「+ 录入证据」，填技能、类型、题干/材料、可见产出，标清辅助级别。
5. **遇到卡点记障碍**（`/diagnosis`）：只记一个主障碍，写清「哪一环卡住 + 样本位置 + 影响」，配一个定向修复动作和成功标准。
6. **用过 AI 就登记**（`/coach`）：记录工具、级别、动作类型、是否采纳；A4 记录单独标红并计入依赖占比。
7. **记录学习明细**：`/records` 录入学习记录（正确率、有效产出、修订留痕）；`/grammar`、`/mistakes`、`/vocabulary`、`/sentences` 按需维护诊断数据。
8. **每周复盘**（`/weekly`）：13 项指标自动计算，Top3 薄弱点必须填满，可一键导出复盘文本。
9. **校准画像**（`/profile`）：四项技能分开看，不取平均、不换算 CEFR 或雅思分数。

**中断了怎么办**：不补积压任务。`/cycle` 的「中断恢复」只给一个 15–24 分钟内能完成的最小下一步。

## 4. 证据化学习（v2.2）

### 4.1 辅助级别 A0–A4

| 级别 | 含义 | 能否算独立产出 |
| --- | --- | --- |
| A0 | 无辅助：不看答案、不用 AI、不查词 | 能，只有 A0 能 |
| A1 | 轻提示：一个方向或关键词 | 不能 |
| A2 | 结构提示：模板、提纲、逐句点评 | 不能 |
| A3 | 局部改写：AI 改一段供对照 | 不能 |
| A4 | 代写/代答：整段或整题由 AI 生成 | 永远不能 |

内部评分 0–2：0 = 没完成；1 = 部分完成/依赖提示；2 = 在标明条件下独立完成。A1–A4 最高只能给 1 分。

### 4.2 证据级别 QUICK / STANDARD / FULL

| 级别 | 建议预算 | 适合记录 |
| --- | --- | --- |
| QUICK | 16–59 分钟 | 60–90 秒口语录音、5 道细节题、100 词短文 |
| STANDARD | 60–179 分钟 | 完整 Task 2、完整听力 Part、真实会议记录 |
| FULL | ≥180 分钟 | 整套模考、完整项目产出的前后对照 |

### 4.3 证据链 E0–E5

```
E0 基线 → E1 辅助版本（可选）→ E2 即时复测 → E3 延迟复测（换平行材料）
        → E4 实际应用 → E5 迁移验证（换新条件）
```

- 基线必须 A0；辅助版本必须真有工具介入（A1–A4），两者不能混在一条记录里。
- 延迟复测至少隔 7 天，且必须换平行材料，不是重复原题。
- 迁移验证必须换新题/新材料/新情境；**重做原题只能记实际应用**，系统会拒绝把它当迁移。

### 4.4 复测阶梯

| 类型 | 间隔 | 默认时长 | 完成时记为 |
| --- | --- | --- | --- |
| 即时复测 | 当天（D0） | 10 分钟 | IMMEDIATE_RETEST |
| 延迟复测 | 7 天 | 15 分钟 | DELAYED_RETEST |
| 实际应用 | 30 天 | 20 分钟 | APPLIED_TASK |
| 迁移验证 | 84 天 | 25 分钟 | TRANSFER |

同一条证据链只维护一套阶梯；重复触发生成不会产生重复排期。

### 4.5 90 天周期

| 阶段 | 天数 | 主要动作 |
| --- | --- | --- |
| 校准 CALIBRATION | 第 1–14 天 | 确认真实目标、四项基线、主要障碍、每周可持续时间 |
| 积累 BUILD | 第 15–56 天 | 每周一个主问题；输入 → 输出 → 反馈 → 迁移证据 |
| 交付 DELIVER | 第 57–90 天 | 换真实场景，完成独立交付与迁移验证 |

阶段推进是建议 + 门禁检查，系统不自动升阶段。

## 5. 词汇引擎（v2.3）

### 5.1 定位

OS 负责计划、词库、证据与统计；TypeWords 负责逐词练习。两者是**独立应用**，只通过你手动导出/导入的文件交换数据。OS 不连接 TypeWords 的浏览器存储，也不自动写入。

TypeWords 固定版本：commit `1bcc2a2c0a169b37bea26b73f5a46a91d803558f`（GPL-3.0）。建议给 TypeWords 使用独立浏览器配置，避免导入词库时覆盖日常词库。

### 5.2 词汇页面地图

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| 词汇概览 | `/vocabulary` | 七维掌握汇总、最近会话、今日任务入口、已知限制 |
| 今日词汇任务 | `/vocabulary/today` | 按当日预算生成词汇分配；导出 TypeWords 兼容词库 |
| 词库与导入 | `/vocabulary/library` | 词库与词条维护 |
| 数据交换 | `/vocabulary/sync` | 导入 TypeWords 备份（.zip/.json）、查看同步任务结果 |
| 词汇分析 | `/vocabulary/analytics` | 每日词汇时长、模式分布、七维覆盖、延迟复测、计划 vs 实际 |
| 连接与版本 | `/vocabulary/connection` | FILE/BRIDGE 连接模式说明、审计基线、已知限制 |
| 词详情 | `/vocabulary/words/<id>` | 录入维度证据、查看复测排期 |
| 旧版词汇表 | `/vocabulary/legacy` | v2.1 三档掌握与抽测，历史数据完整保留 |

Dashboard（`/`）区块⑥b 只显示四个可核对数字：词条总量、到期未复习、复测到期、今日新词条。

### 5.3 方向 A：TypeWords 练习 → OS 统计（常用）

1. TypeWords「设置 → 数据管理 → 导出数据备份(ZIP)」，得到 `TypeWords-User-Data-*.zip`。
2. 打开 OS `/vocabulary/sync`。
3. 选择该 `.zip`（无需解压；也可以只选包里的 `data.json`）。
4. 勾选「把汇总会话计入学习时长」（默认开启），点「导入备份」。
5. 看「同步任务」表结果：
   - `words.created`：新增词条数；
   - `sessions.imported`：导入的练习会话数；
   - `minutesCounted`：计入的学习分钟（与已有记录重叠的部分已扣除）。

说明：

- TypeWords 导出会裁掉内置词典的单词正文（如 CET-4），这类备份词条数为 0，只导入统计，界面会提示「备份未包含词条正文」。
- 备份没有逐词结果，导入的会话固定为 **SUMMARY_ONLY**，不会推进七维掌握。
- 同一条统计重复导入会被跳过（幂等），不会重复计时。

### 5.4 方向 B：OS 词库 → TypeWords 练习

1. 在 `/vocabulary/today` 选择词库并「导出」。
2. 得到 `<词库名>-typewords-<日期>.json`。
3. TypeWords「设置 → 数据管理 → 导入数据」选择该文件。
4. 导入前先备份；导入后 TypeWords 的词典会被替换为这一个自定义词库（整库覆盖）。

该文件是最小兼容备份（`version:5`、`val.dict.version:4`、`setting.version:23`），只含词条正文与空统计。

### 5.5 七维掌握与证据

- 入口：`/vocabulary/words/<id>` 的「录入证据」表单。
- 维度：词形识别、词义识别、词义回忆、拼写回忆、听力识别、语境理解、产出使用。
- 规则：语境理解需 E2+ 证据；产出使用需 E4/E5；辅助级别 A0–A4 参与判定。
- 延迟复测：状态达到「回忆」及以上才排期（隔日 / 7 天 / 30 天）；同词同维度的新证据只结清**已到期**的复测，未来排期保留。

### 5.6 词汇功能已知限制

| 编号 | 限制 | 影响 |
| --- | --- | --- |
| L16 | TypeWords 导出裁剪内置词典正文 | 这类备份只能导入统计，词条需来自自定义词库 |
| L17 | TypeWords 导入是整库覆盖 | OS 只生成文件，不自动写入；导入前先备份 |
| L18 | 备份无逐词结果 | 导入会话固定 SUMMARY_ONLY，不推进七维 |
| L19 | 备份 ZIP 仅支持 store/deflate | ZIP64、加密包需先解压再选 `data.json` |
| L20 | 练习统计只在会话结束/切换时落库 | 中途退出的进度在 TypeWords 的 PracticeSaveWord 缓存里，未必形成统计 |

## 6. 每周复盘与阶段验收

- `/weekly`：13 项指标自动计算（时长、配比、正确率、复习完成率等），可手工覆盖；Top3 薄弱点必须填满；可一键导出复盘文本。数据分析看板是 `/weekly?tab=analytics` 的一个 Tab（10 张图表 + 全局筛选）。
- `/stages`：4 阶段、28 条验收项；H1–H5 门禁**只给建议，绝不自动升级**；升级动作留痕。
- `/cycle`：90 天周期的校准/积累/交付门禁与每周主问题。
- `/library`、`/resources`：方法论与资源元数据，不复制原文。

## 7. 数据、备份与恢复

- 所有数据在本地 `prisma/dev.db`（SQLite 单文件），不上传云端。
- **不要直接 `cp` 运行中的 `dev.db`**，用一致性快照：

```bash
bash scripts/backup.sh                     # 生成 backups/dev-YYYYMMDD-HHMMSS.db 并自检
bash scripts/restore.sh <备份文件>          # 高风险：覆盖前自动留安全网，需二次确认
```

- 定时备份：`scripts/backup-launchd.plist.template`（macOS launchd 模板，只交付模板不自动安装）。
- 导出：`/settings` 提供 CSV / JSON 五类领域数据导出。
- 迁移到新机器：复制仓库 + `prisma/dev.db` + `.env`，然后 `npm i` → `npx prisma generate`；**不要**再跑 `db push` / `db:reset`。

### 7.1 版本化迁移

```bash
bash scripts/backup.sh                                          # 升级前备份
node scripts/migrations/v2.3.mjs --db prisma/dev.db --dry-run    # 只看 DDL
node scripts/migrations/v2.3.mjs --db prisma/dev.db              # 正式迁移
```

- 迁移是纯加法（新增词汇域 12 表、集成 2 表，并把既有 VocabWord 幂等迁入 VocabularyItem）；
- 单事务、可重复执行，checksum 不一致时拒绝执行；
- 写入 AppMigration 版本记录并做 integrity_check / foreign_key_check。

回滚：`bash scripts/restore.sh backups/<升级前备份>`，随后 `npm run db:generate`。

## 8. 常见问题

**Q：为什么我重做原题，系统不让我记「迁移验证」？**
A：迁移验证要证明「换成新条件后依然能做到」。重做原题只能说明记住了这道题，所以只能记「实际应用」。

**Q：预算只有 15 分钟，也要做完整证据链吗？**
A：不用。≤15 分钟属维持性练习；16–59 分钟建议 QUICK，60 分钟以上建议 STANDARD，180 分钟以上才建议 FULL。

**Q：AI 帮我改了一整段，为什么不算我的产出？**
A：A4 是代写/代答，可以帮助学习，但不能作为「能独立做到」的证据。撤掉 AI 后自己重写一版并记 A0，才进证据链。

**Q：画像里的置信度 HIGH 等于雅思 7 分吗？**
A：不等于。置信度只表示这批证据能支撑多强的方向判断，不是分数换算；四项技能分开看。

**Q：中断了两周，要不要补回落下的任务？**
A：不补。周期的「中断恢复」只给一个 15 分钟内能完成的最小下一步，恢复节奏比补齐更重要。

**Q：复测和复习中心有什么区别？**
A：复习中心管知识型记忆（词汇、错题、语法点）；复测管技能表现（能否在无辅助下做到）。两套队列不共享状态。

**Q：TypeWords 备份导入后词条为 0？**
A：备份来自内置词典，正文被 TypeWords 裁掉了。正常现象，只有统计可用；词条需来自自定义词库。

**Q：提示「ZIP 里没有 data.json」？**
A：选错文件（如其他软件的压缩包）。重新在 TypeWords 导出备份。

**Q：提示「ZIP 条目过大/压缩方式不支持」？**
A：非标准压缩包（ZIP64、加密、bzip2 等）。解压后直接选择 `data.json`。

**Q：导入后学习时长没有增加？**
A：与已有学习记录时间重叠，重叠区间只计一次，属预期行为。

**Q：在 TypeWords 导入 OS 词库后，原来的词库没了？**
A：TypeWords 导入是整库覆盖。用导入前的备份在 TypeWords「数据管理」恢复。

**Q：页面时间和我本地时间差 8 小时/一致但日期不对？**
A：全站按 Asia/Singapore（UTC+8）归属业务日与展示时刻；这是设计口径，不是错误。

## 9. 口径边界（请勿误读）

- 阶段名称、目标分、模考分都是个人记录与路径标签，不代表 CEFR 认证或官方成绩。
- SkillProfile 的方向描述不是评级；「没有证据」和「证据显示较弱」是两件事。
- 汇总会话（SUMMARY_ONLY）只计入时长，不推进七维掌握。
- 资料库只存外部资源元数据、链接与个人摘要，不复制原文。
- TypeWords 为 GPL-3.0 独立应用，本仓库不含其源码。

## 10. 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `command not found: npm` | 未安装 Node.js | 用 Homebrew 安装 Node ≥20 |
| 端口 3000 被占用 | 已有 dev server 在跑 | 先停掉旧进程，或换端口启动 |
| 页面停在「正在加载数据」 | dev server 未就绪或构建异常 | 查看终端报错；重新 `npm run dev` |
| 启动即报 Prisma 错误 | 客户端未生成 | `npm run db:generate` |
| 恢复备份后表结构报错 | 代码版本与库版本不一致 | 按第 7.1 节执行对应版本迁移，再 `npm run db:generate` |

切勿用 `npm run db:reset` 处理以上问题——它会清空全部学习数据。
