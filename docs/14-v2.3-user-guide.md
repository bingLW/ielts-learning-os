# v2.3 用户手册：TypeWords 词汇引擎集成

本版本把「计划里的词汇任务」与 TypeWords 练习打通，但两边仍是**独立应用**：
OS 负责计划、词库、证据与统计；TypeWords 负责逐词练习。两者只通过**你手动导出/导入的文件**交换数据，
OS 不连接 TypeWords 的浏览器存储，也不自动写入。

## 1. 前置

- TypeWords 固定版本：commit `1bcc2a2c0a169b37bea26b73f5a46a91d803558f`（GPL-3.0）。
- 建议给 TypeWords 使用**独立浏览器配置**（或专用浏览器），避免导入词库时覆盖你的日常词库。
- OS 的「导出词库」会生成一个 TypeWords 兼容包；TypeWords 的「导入数据」是**整库覆盖**，
  导入前请在 TypeWords「设置 → 数据管理」先导出一次备份。

## 2. 方向 A：TypeWords 练习 → OS 统计（常用）

1. TypeWords「设置 → 数据管理 → 导出数据备份(ZIP)」，得到 `TypeWords-User-Data-*.zip`。
2. 打开 OS `/vocabulary/sync`（词汇 → 数据交换）。
3. 选择该 `.zip`（无需解压；也可以只选压缩包里的 `data.json`）。
4. 勾选「把汇总会话计入学习时长」（默认开启），点「导入备份」。
5. 看「同步任务」表的结果：
   - `words.created`：新增词条数；
   - `sessions.imported`：导入的练习会话数；
   - `minutesCounted`：计入的学习分钟（与已有记录重叠的部分已扣除）。

说明：

- TypeWords 导出会**裁掉内置词典的单词正文**（如 CET-4），所以这类备份的词条数为 0，
  只导入统计；界面会提示「备份未包含词条正文」。
- 备份没有逐词结果，因此导入的会话都是 **SUMMARY_ONLY**，不会推进七维掌握。
- 同一条统计重复导入会被跳过（幂等），不会重复计时。

## 3. 方向 B：OS 词库 → TypeWords 练习

1. 在 OS `/vocabulary/today`（今日词汇任务）选择词库并「导出」。
2. 得到 `<词库名>-typewords-<日期>.json`。
3. 在 TypeWords「设置 → 数据管理 → 导入数据」选择该文件。
4. 导入前确认已备份；导入后 TypeWords 的词典会被替换为这一个自定义词库。

该文件是一份最小兼容备份（`version:5`，`val.dict.version:4`，`setting.version:23`），
只包含词条正文与空统计。

## 4. 七维掌握与证据

- 入口：`/vocabulary/words/<id>` 的「录入证据」表单。
- 维度：词形识别、词义识别、词义回忆、拼写回忆、听力识别、语境理解、产出使用。
- 规则：语境理解需 E2+ 证据；产出使用需 E4/E5；辅助级别 A0–A4 参与判定。
- 延迟复测：状态达到「回忆」及以上才会排期（隔日 / 7 天 / 30 天）；
  同词同维度的新证据只结清**已到期**的复测，未来排期保留。

## 5. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 导入后词条为 0 | 备份来自内置词典，正文被裁剪 | 正常；只有统计可用 |
| 提示「ZIP 里没有 data.json」 | 选错文件（如其他软件的压缩包） | 重新导出 TypeWords 备份 |
| 提示「ZIP 条目过大/压缩方式不支持」 | 非标准压缩包 | 解压后选择 `data.json` |
| 时长没有增加 | 与已有学习记录时间重叠 | 重叠区间只计一次，属预期 |
| 导入 TypeWords 后词库没了 | TypeWords 导入是整库覆盖 | 用导入前的备份恢复 |

## 6. 数据与隐私

- 全程离线：文件只在你的浏览器与本地数据库之间流转。
- OS 不保存 TypeWords 的连接凭据，也不访问其 IndexedDB。
- 所有时间按 **Asia/Singapore（UTC+8）** 展示与归属业务日。
