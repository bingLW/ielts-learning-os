# IELTS Learning OS v2.5 — Listening & Speaking Lab

在 v2.4.1 基础上增量交付「听力与口语训练、诊断、证据采集与复测」工作台。把音频、转写、任务、作答与学习证据整合为一个闭环，并增强 v2.4.1 的听说基线与复测能力。

## 新增能力

- **听力实验室 `/listening`**：音频上传（mp3/m4a/wav/webm/ogg/aac，≤50MB）、播放器（0.75/1/1.25x 变速、A-B 循环、Range 拖动）、转写对照、练习与作答；首听结果与辅助后结果分字段保存，绝不覆盖。
- **口语实验室 `/speaking`**：麦克风录音（MediaRecorder）、回放、重录保留历史 take（`takeNumber` 递增）、九类口语题目、会话与轮次记录。
- **本地文件落盘**：音频/录音写入 `storage/uploads`（gitignore），DB 只存相对路径 + sha256；`/api/audio/[id]` 流式读取，支持 Range 拖动。
- **ASR Provider Adapter**：`src/lib/speech/provider.ts` 可替换抽象；当前未接真实供应商，走手动转写降级（有意的安全默认，不产生外部请求）。
- **退出系统**：`/settings` 底部新增二次确认关闭本机应用进程。
- **错误分类**：听力错误 11 类，`AUDIO_QUALITY` 等技术问题不计为英语能力错误。

## 数据库迁移

- 版本化迁移 `v2.5`：纯加法，新增 13 张表（AudioAsset、Transcript、TranscriptSegment、ListeningExercise、ListeningAttempt、ListeningError、SpeakingPrompt、SpeakingSession、SpeakingTurn、RecordingAsset、ASRResult、SpeechEvaluation、AudioTechnicalCheck）。
- 单事务 `BEGIN IMMEDIATE`，迁移后 `integrity_check=ok`、`foreign_key_check` 0 行、核心表行数零漂移。
