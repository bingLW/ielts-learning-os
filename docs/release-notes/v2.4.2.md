# IELTS Learning OS v2.4.2 — Provider 凭据页面配置入库

在 v2.4.1 基础上增量交付「凭据在管理页自助配置 → 加密入库 → 全局生效」的闭环。此前 API Key 只能写进环境变量并重启应用，现在改为在页面填写、保存即用；AI Coach 与诊断开放任务共用同一份凭据。

## 新增能力

- **Provider 凭据表单**：`/ai-coach/admin` 新增 API Key、Base URL、模型名三项配置，保存后立即生效，无需改 `.env`、无需重启。
- **加密入库**：新增单行表 `AIProviderCredential`；API Key 以 AES-256-GCM 加密存储，只保留末四位用于页面回显，页面与 Server Action 返回值均不含明文或密文。
- **凭据优先级**：管理页配置（数据库）> 环境变量 `AI_PROVIDER_API_KEY` > 未配置（回落 Mock）；AI Coach 与诊断开放任务共用。
- **一键清除**：点「清除 API Key」立即回落环境变量或 Mock。
- **密钥来源**：优先取 `AI_CREDENTIALS_SECRET`（scrypt 派生），否则自动生成 `.local/ai-credentials.key`（0600，已 gitignore）；可用 `AI_CREDENTIALS_KEY_FILE` 改路径。

## 数据库迁移

- 版本化迁移 `v2.4.2`：纯加法，仅新增 1 张表 `AIProviderCredential`，不改任何既有列。
- 单事务 `BEGIN IMMEDIATE`，同版本 checksum 不一致拒绝执行；迁移后 `integrity_check=ok`、`foreign_key_check` 0 行、受保护表行数零漂移。
- checksum：`2c5b43e6736cbed7`；报告：`backups/migrations/v2.4.2-2026-11-22T08-43-53-390Z.json`。
- 回滚：用迁移前备份 `bash scripts/restore.sh backups/<升级前备份>`，随后执行 `npm run db:generate`。

## 已知限制

- **L32 密钥不随数据库迁移**：只复制 `dev.db` 到新机器时无法解密已存 Key，页面会提示重新填写；或改用 `AI_CREDENTIALS_SECRET` 统一密钥。更换 secret 会使已存 Key 失效。
- **L33 管理页无账号鉴权**：本项目为单用户本机应用；能访问 `/ai-coach/admin` 的人即可修改凭据，部署到公网前必须加访问控制。
