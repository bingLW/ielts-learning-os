# IELTS Learning OS v2.4.1 — AI 初始诊断与智能定级

在 v2.4 基础上增量交付「初始能力诊断 → 可追溯证据 → 分技能画像 → 计划草案 → 用户确认」的闭环。

## 新增能力

- **多时段诊断会话**：一次一题，可暂停/继续；刷新或换时段后进度不丢
- **自适应难度路由**：答对插入更难平行题，答错回落到基础题，每步给出可解释理由；每个客观技能最多 2 题
- **题库驱动**：21 道种子题（Listening / Reading / Speaking / Writing / Grammar / Vocabulary / Sentence Structure / 可选 EMLR），不在运行时由 LLM 现编题目
- **客观题确定性判分**：选择题支持键位与选项文本两种写法；填空题归一化后比对
- **开放任务 rubric 评分**：口语/写作先展示评分维度再作答；外部 AI 未启用时保持「待评估」，绝不用模拟结果定级
- **技术无效标记**：设备/音频/环境失败不计分、不产生证据，并自动重新排队
- **分技能能力画像**：四项核心技能各自给出等级或范围、置信度、证据数、覆盖度、局限，**不平均成总体 CEFR**
- **报告 append-only**：补测开启新会话与新报告，旧报告保留可对比
- **7/30/90 天计划草案**：复用 v2.1 动态时间预算，每项任务标注关联证据与安排原因；用户编辑确认后仅置 `ACTIVE`，不自动创建 PlanTask
- **隐私**：录音以 data URL（≤1.6MB）存本机 SQLite；删除诊断会话同时清掉本轮作答、录音、证据、快照、报告与草案

## 修复

- 未勾选「外部 AI 同意」时，诊断开放任务不再外发，即使后台已启用外部 AI 也保持「待评估」（新增回归测试 `src/lib/diagnostic/__tests__/ai.test.ts`）

## 已知限制

- 未启用外部 AI 时，口语/写作不产出等级，报告标为「暂定」并建议补测
- 发音不单独评分（不以 ASR 结果评发音）
- 等级为 AI 辅助 CEFR 估计，非官方认证，不预测 IELTS 分数
- 题库仅 21 道种子题，技能覆盖广度有限
- 听力播放依赖浏览器 SpeechSynthesis
