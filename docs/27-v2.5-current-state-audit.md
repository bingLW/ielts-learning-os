# v2.5 现状审计 — Listening & Speaking Lab 开发前盘点（2026-11-22）

本文件为 v2.5 Listening & Speaking Lab 的 Phase 0 交付。结论均来自对当前仓库代码、Prisma Schema 与既有实现的核查，不是推测。

## 1. 当前音频 / 录音 / 附件能力

| 能力 | 现状 | 位置 |
| --- | --- | --- |
| 诊断录音 | 仅诊断域有：`DiagnosticAsset`（`kind=AUDIO`，`storagePath` 存 **data URL**，≤1.6MB / 90 秒），浏览器 `MediaRecorder`（audio/webm） | `prisma/schema.prisma`、`src/components/diagnostics/DiagnosticWorkspace.tsx` |
| 听力播放 | 仅 `SpeechSynthesis`（浏览器 TTS 朗读文本），无音频文件播放器 | `DiagnosticWorkspace.tsx` 第 82 行 |
| 附件 | `EvidenceAttachment.fileUri` 只存字符串（相对路径或 data URL），**无真实文件系统落盘**；无上传 API 路由 | `prisma/schema.prisma` |
| 通用文件上传 | **缺失**：`src/app/api/` 下仅 `export/[kind]` 导出路由，无 upload 路由 | — |

**结论**：v2.5 需要**新建**本地文件落盘存储（音频上传/录音），并复用诊断域的 MediaRecorder 录音交互。

## 2. ASR / TTS / 语音评估 Provider 现状

| 服务 | 现状 |
| --- | --- |
| ASR（语音转文字） | **无**。无任何 ASR Provider Adapter |
| TTS | 无（只有浏览器 `SpeechSynthesis`） |
| 语音分析 / 发音评估 | 无 |
| 文本 AI | 已有 `AiProvider`（Mock 确定性 + OpenAI 兼容外部通道），`src/lib/ai/provider.ts` |

**结论**：需新建 `src/lib/speech/` 抽象层（可替换 Provider Adapter），复用 v2.4 的 Provider 模式；**无外部 ASR 时必须提供手动转写降级**（约束 §9）。

## 3. 可复用的既有资产

| 资产 | 复用方式 |

| `Card/Button/FormField/Toast/ChartFrame` | 新页面视觉一致 |

## 4. 费用 / 隐私 / 数据保留风险

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 音频体积 | SQLite 存 data URL 会膨胀（v2.4.1 限制 ≤1.6MB/90s） | v2.5 改为**文件系统落盘**（`storage/uploads`，gitignore），DB 只存相对路径 + sha256 |
| 外发隐私 | 录音/转写属个人数据，外发 AI 前须同意 | 沿用 `consentStatus` + `externalAiConsent` 模式；`privacy.ts` 脱敏 |
| ASR 误判 | 低置信度转写/口音/噪声不得记为能力错误 | `INVALID`/技术质量与英语能力分离；低置信度提示核验 |
| 删除派生数据 | 删录音须同时清转写/反馈/证据引用 | 明确删除级联规则（`onDelete: Cascade`） |
| 时长重复计算 | 播放/重复播放不能等于专注分钟 | 播放时长与净学习时长分离；计时唯一 session source（不变量 1/10） |

## 5. 实施拆分（对应提示词 Phase A–F）

| Phase | 内容 | 新增表 |
| --- | --- | --- |
| A | 音频上传 + 本地落盘 + 播放器（进度/速度/A-B 循环/逐句） | `AudioAsset` |
| B | 九种听力训练模式 + 错误分类（首听/辅助后分离） | `ListeningExercise`/`ListeningAttempt`/`ListeningError` |
| C | ASR 转写 Adapter + 手动转写降级 | `Transcript`/`TranscriptSegment`/`ASRResult` |
| D | Speaking Recorder（录音/回放/重录/版本保留） | `RecordingAsset`/`SpeakingPrompt` |
| E | 口语任务 + AI 对话伙伴 + 反馈 + 评分 | `SpeakingSession`/`SpeakingTurn`/`SpeechEvaluation`/`AudioTechnicalCheck` |
| F | 诊断集成 + Planner 接入 + 退出系统功能 | 复用既有表 |

## 6. 退出系统关闭程序功能（用户追加需求）

现状：单用户本地 Next.js 应用，无账号/登录体系，无「关闭程序」入口。需新增：`/settings` 或侧栏「退出系统」按钮 → 前端二次确认 → 服务端优雅关闭进程（`process.exit(0)`）+ 前端提示。这是 v2.5 的独立追加项，不进上述 Phase。
